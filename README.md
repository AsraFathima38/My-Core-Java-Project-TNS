# Core Java Practice

##  About the Project

This repository contains Core Java practice programs and exercises covering fundamental Java concepts and object-oriented programming.

The project is intended for learning, practicing, and understanding Java programming concepts through practical examples.

##  Technologies Used

* **Java**
* **Eclipse IDE / Java Development Tools**
* **Git & GitHub**

The project includes practice related to:

* Java Basics
* Variables and Data Types
* Operators
* Conditional Statements
* Loops
* Arrays
* Strings
* Methods
* Classes and Objects
* Constructors
* Inheritance
* Polymorphism
* Encapsulation
* Abstraction
* Exception Handling
* Collections
* Other Core Java concepts

##  How to Run

1. Install the **Java JDK** on your system.
2. Clone this repository:


git clone https://github.com/AsraFathima38/My-Core-Java-Practice.git


3. Open the project in **Eclipse** or another Java IDE.
4. Select the required Java file.
5. Run the program as a Java Application.
